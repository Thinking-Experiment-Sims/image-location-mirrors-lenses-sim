# Location of Images in Mirrors and Lenses Lab

Interactive simulation for 11th-grade optics focused on principal ray construction and image formation.

## What is included

- Four optical elements: convex lens, concave lens, concave mirror, convex mirror.
- Color-coded principal rays (Ray 1, Ray 2, Ray 3) with virtual extensions.
- Real-time image calculations using:
  - `1/do + 1/di = 1/f`
  - `m = -di/do`
  - `m = hi/ho`
- Practice mode with random challenges and instant prediction feedback.
- Guided ray-drawing instructions for each optical element.

## Run locally

1. Open `index.html` directly, or serve the folder with any static server.
2. Adjust controls and toggle rays to inspect each rule.
3. Use `New Practice Challenge` to start Predict -> Observe -> Explain cycles.

## Design baseline

Built from the Thinking Experiment simulation template with the default dark refraction visual system and gold-accent interaction pattern.
